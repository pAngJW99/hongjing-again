# 再见，宏景

一个以“宏景”为舞台的像素风横版互动地图。游客可以在场景中移动、探索地点、收集邮戳与故事便签。

## 当前场景：宏景火车站

- 老式站台、绿色长椅、小卖部与远处城市山线
- 火车离站动画、随风飘动的广告纸和环境音
- 键盘与手机触屏移动
- 地点邮戳「回到宏景」
- 未署名的星形便签

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```

## 项目说明

这是一个非商业性质的同人互动体验。场景、美术和剧情仍在持续完善中。
